# TMIS 数据批量抓取工具 V5.0

> 基于 Playwright + Tkinter 的全自动 TMIS 内网数据抓取桌面工具。支持批量参数化查询、一键导出、数据后处理。

---

## ✨ 核心功能

| 功能 | 描述 |
|---|---|
| **URL 狙击手** | 10ms 极限轮询捕获客户端登录 Token 链接，自动拦截并启动 Chrome 执行任务 |
| **收支分流** | 同一批次中混合执行收入与支出查询，自动切换侧边栏导航 |
| **智能标签页管理** | 收支类型切换时自动关闭旧标签页，防止多标签页 DOM 冲突导致元素定位错误 |
| **参数化驱动** | 通过 Excel 双 Sheet（收入参数 / 支出参数）全中文表头驱动执行 |
| **数据后处理** | 自动新增"预算级次"列、剔除计划单列市、统一单元格格式 |
| **智能命名** | 支持参数表自定义命名或按规则自动命名，自动去重 |

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install playwright pandas openpyxl psutil
pip install pyperclip  # 可选，用于复制链接到剪贴板
playwright install chromium
```

### 2. 生成参数模板

```bash
python "TMIS数据批量抓取工具V5.0.py" --template
```

生成文件 `TMIS参数模板_v5.0.xlsx`，包含两个 Sheet：

| Sheet | 用途 |
|---|---|
| `收入参数` | 收入查询参数行（每行一次查询） |
| `支出参数` | 支出查询参数行（每行一次查询） |

### 3. 运行工具

```bash
python "TMIS数据批量抓取工具V5.0.py"
```

工具启动后按以下步骤操作：

1. **选择 Excel 参数文件**（填好的模板）
2. **选择下载保存目录**
3. **设置日期**（默认当天，Excel 参数优先）
4. **点击「捕获登录链接」**
5. **在客户端触发系统登录**
6. 程序自动拦截 Token → 启动 Chrome → 依次执行全部任务

## ⚙️ 数据后处理

勾选「启用数据后处理」后，导出的 Excel 文件将自动执行：

1. **新增"预算级次"列**
   - `pBdgLevel` 为 `0` 或空 → 填充 `"0"` (全口径)
   - `pBdgLevel` 为其他值 → 填充 `"6"` (地方级)

2. **剔除计划单列市**（仅当 `pByTre = 3` 即市级时触发）
   - 自动删除"国库简称"列中包含深圳市、厦门市、青岛市、宁波市、大连市的行

3. **统一单元格格式**
   - 将"本期执行数"、"同期执行数"、"同比增速(%)"、"年累计"、"同期年累计"、"年累计同比增速(%)" 列设为 `General` 格式

## 🏗 架构概览

```
TMISAutoApp (tk.Tk)
├── _build_gui()                   # 深色主题 UI 构建
├── _start_sniper()                # URL 狙击手（Token 捕获）
├── _run_automation()              # 核心异步自动化循环
│   ├── _navigate_sidebar_smart()  # 智能侧边栏导航 + 标签页管理
│   │   └── _close_current_tab()   # 关闭旧标签页（仅在收支切换时触发）
│   ├── _fill_form()               # 表单填充（下拉/日期/文本/复选框）
│   ├── _click_query_and_wait()    # 查询 + 等待 iframe 内导出按钮可用
│   ├── _export_and_save()         # force=True 导出 + 文件保存
│   └── _process_excel_data()      # 数据后处理
├── _build_filename()              # 智能/自定义文件命名
└── generate_template()            # Excel 参数模板生成
```
