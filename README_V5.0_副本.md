# TMIS 数据自由查询批量抓取工具 V5.1

> 基于 Playwright + Tkinter 的 TMIS 网页版（new 新系统）数据自由查询批量下载工具。当前支持收入、支出、退库、库存四类正常期月报。

---

## 核心功能

| 功能 | 描述 |
|---|---|
| URL 狙击手 | 轮询捕获客户端弹出的 Token 登录链接，自动启动 Chrome 执行任务 |
| 四类自由查询 | 支持 `收入数据自由查询`、`支出数据自由查询`、`退库数据自由查询`、`库存数据自由查询` 四个菜单 |
| 配置驱动 | 页面菜单名、iframe、字段、复选框和模板列集中维护在 `REPORT_CONFIGS` |
| 参数化驱动 | Excel 多 Sheet 驱动任务，支持混合执行收入、支出、退库、库存 |
| 智能标签页管理 | 类型切换时自动关闭旧标签页，避免隐藏 DOM 干扰定位 |
| 精确命名 | 支持 `文件名称`、`是否追加日期`、`保留原文件名` 控制导出文件名 |
| 数据后处理 | 可选新增预算级次列、剔除计划单列市、统一数值列格式 |

## 快速开始

### 1. 安装依赖

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

### 2. 生成空白参数模板

```bash
python "TMIS数据批量抓取工具V5.0_副本.py" --template
```

默认生成：

```text
TMIS数据自由查询参数模板_v5.1.xlsx
```

模板包含四个 Sheet：

| Sheet | 用途 |
|---|---|
| `收入参数` | 收入数据自由查询任务 |
| `支出参数` | 支出数据自由查询任务 |
| `退库参数` | 退库数据自由查询任务 |
| `库存参数` | 库存数据自由查询任务 |

### 3. 使用核对专用参数表

仓库已提供一份按附件 2 要求生成的网页版 new 正常期参数表：

```text
TMIS网页版new正常期收入支出退库库存参数表_1009000000_v5.1.xlsx
```

该表按 `1009000000` 国库代码生成：

| Sheet | 文件名范围 | 日期范围 |
|---|---|---|
| `收入参数` | `newsr2003` 到 `newsr2026` | 2003-2025 全年，2026 为 `202601-202603` |
| `支出参数` | `newzc2003` 到 `newzc2026` | 2003-2025 全年，2026 为 `202601-202603` |
| `退库参数` | `newtk2003` 到 `newtk2026` | 2003-2025 全年，2026 为 `202601-202603` |
| `库存参数` | `newkc2004` 到 `newkc2026` | 2004-2025 全年，2026 为 `202601-202603` |

库存参数按附件 2 分段填写会计科目：

| 年份 | 会计科目 |
|---|---|
| 2004-2007 | `2510,2520,2530` |
| 2008-2026 | `271,272,273` |

专用表中 `是否追加日期=0`、`保留原文件名=0`，导出文件会按附件 2 命名规则精确保存，例如 `newsr2003.xlsx`。

### 4. 运行工具

```bash
source .venv/bin/activate
python "TMIS数据批量抓取工具V5.0_副本.py"
```

运行步骤：

1. 选择 Excel 参数文件。
2. 选择下载保存目录。
3. 设置日期、命名模式、是否启用后处理。
4. 点击「捕获登录链接」。
5. 在客户端触发系统登录。
6. 程序捕获 Token 后自动启动 Chrome 并批量执行任务。

## 页面与 iframe

| 数据类型 | 菜单路径 | iframe |
|---|---|---|
| 收入 | `固定报表 -> 数据自由查询 -> 收入数据自由查询` | `fineReportTsasRpt6010` |
| 支出 | `固定报表 -> 数据自由查询 -> 支出数据自由查询` | `fineReportTsasRpt6020` |
| 退库 | `固定报表 -> 数据自由查询 -> 退库数据自由查询` | `fineReportTsasRpt6030` |
| 库存 | `固定报表 -> 数据自由查询 -> 库存数据自由查询` | `fineReportTsasRpt6040` |

字段定位使用可见容器：

```python
page.locator(f'.el-form-item:visible:has(label[for="{field_id}"])')
```

这样可以避开 SPA 中隐藏旧标签页遗留的同名字段。

## 参数字段

### 通用字段

| 列名 | 对应字段 | 说明 |
|---|---|---|
| 文件名称 | - | 导出文件名前缀或精确文件名 |
| 是否追加日期 | - | `1` 追加日期，`0` 不追加 |
| 保留原文件名 | - | `1` 拼接系统原始文件名，`0` 只保留自定义文件名 |
| 报表库选择 | `pRptDbType` | 示例：`1 -- 报表库` |
| 调整期标志 | `pTrimFlag` | 正常期为 `0 -- 正常期` |
| 报表类型 | `pRptType` | 月报为 `3 -- 月` |
| 起始日期 | `pStartDate` | 示例：`200301` |
| 终止日期 | `pEndDate` | 示例：`200312` |
| 国库选择 | `pTreCode` | 示例：`1009000000` |
| 辖属标志 | `pGovernFlag` | 示例：`0 -- 全辖` |
| 预算级次 | `pBdgLevel` | 示例：`0` |
| 预算科目 | `pSbtCode` | 示例：`ALL` |
| 计划单列市/县/乡 | `pSigTreArea` | 示例：`0 -- 不含` |
| 科目级次 | `pStatSbtLevel` | 示例：`4 -- 目` |
| 金额单位 | `pAmtUnit` | 示例：`0 -- 元` |

## 当前边界

- 附件 2 中的调整期年报使用 `固定报表 -> 国库收支存明细表`，属于另一个下载路径，不在当前自由查询 V5.1 参数表中。
- 真实下载仍需 TMIS 内网 Token 登录环境。

库存后处理：启用数据后处理时，如果导出表存在 `所属市国库代码` 列，会自动删除该列，用于处理附件 2 提到的省分库库存报表差异。
